# 淡路島修学旅行｜里山みらくる小学校

## ローカル確認

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

http://127.0.0.1:4173/ を開きます。ビルド不要のHTML / CSS / JavaScriptです。

## 更新・公開

- `index.html`: 掲載内容
- `style.css`: デザインとスマホ表示
